# xroam Homebrew tap

PC側のxroamセットアップを配布する個人用tapです。

```sh
brew install tamoharu/xroam/xroam
xroam setup
```

旧版から切り替える場合は、作業完了後に設定・履歴を移行し、iPhoneでQRを再登録してください。

[セットアップと操作](https://github.com/tamoharu/xroam-setup) · [移行手順](https://github.com/tamoharu/xroam-setup/blob/main/docs/RENAMING.md) · [リリース](https://github.com/tamoharu/xroam-setup/releases/latest)

macOS / Linux、Node.js 24、tmux、OpenSSLに対応。iPhoneアプリ本体・ソースは含みません。
